# YOLOv5s 板端模型替换与性能对比报告

> **板端**: Orange Pi 5 Pro (RK3588S), NPU driver 0.9.6
> **日期**: 2026-07-12

| 条件 | 值 |
|------|-----|
| 测试视频 | video.mp4 (1080p) |
| 预热次数 | 50 |
| 测量帧数 | 900 |
| 线程数 | 1 / 6 |
| 阈值 | box=0.5, nms=0.5 |

## 模型信息

| 属性 | 旧模型 | 新模型 (INT8-Normal) |
|------|--------|---------------------|
| 文件名 | yolov5s.rknn | yolov5s_relu_INT8_Normal.rknn |
| Toolkit | 1.5.2 | 2.3.2 |
| 输入 | [1,3,640,640] NHWC INT8 | [1,3,640,640] NHWC INT8 |
| 输出 | 3x INT8 NCHW | 3x INT8 NCHW |

| 模型大小 | ~8 MB | 7.99 MB |

## 关键发现: 输出值域不兼容

旧模型输出原始 logit（值域 [-18, 7]），后处理通过 sigmoid 映射到 [0,1]。
新模型(Toolkit 2.3.2)在量化时已将输出范围记录为 [0,1]（已过 sigmoid），
导致后处理中 sigmoid 被调用两次 -> 置信度膨胀 -> 候选框从 201 暴增至 3015。

**修复**: 新增 --skip-sigmoid 参数，跳过重复的 sigmoid 激活。

## 结论

1. **推理速度提升**: INT8-Normal rknn_run 16.6ms (snapshot单帧, 不含输入输出开销), 比旧模型(31.5ms)快 1.9x; benchmark 900帧均值约17.8ms
2. **吞吐提升**: 6线程 153 FPS, 比旧模型(112 FPS)提升 37%
3. **后处理修复**: --skip-sigmoid 使后处理从 176ms 降至 9.7ms (18x 加速)
4. **Runtime 版本不影响性能**: G1 vs G2 差距 < 2%
5. **推荐**: INT8-Normal + --skip-sigmoid 作为新默认配置
