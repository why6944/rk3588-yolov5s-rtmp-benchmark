## 改动范围

先以独立提交 `f030147` 整合板端已运行过的九个相关源码文件：逐帧单调时钟埋点、CSV 与分位数输出、RGA 中间缓冲 DMA heap/fd 路径、采集 buffer 背压，以及默认不启用的 CPU 预处理诊断路径。随后移动目录并调整 CMake、头文件搜索路径和运行脚本。

正式代码位于 `src/`，入口为 `src/main.cpp`。模型、第三方库和主程序产物位置分别保持为 `model/`、`3rdparty/`、`build/app`。历史实验材料移动到 `experiments/`，没有删除数据；已发布的延时 CSV 继续位于 `docs/latency_data/`。

验证在同一块 Orange Pi 的独立临时目录 `/tmp/rk3588-integration-pPiFYE` 进行，第三方库与模型通过只读用途的路径引用沿用原工程，未在原工程执行目录重排、Git 更新或重新构建。临时目录可能在重启后消失。
