# 新 RKNN 模型复现实验

本仓库包含两份用于对比的 YOLOv5s INT8 RKNN 模型：

| 模型 | 路径 | 输出说明 |
| --- | --- | --- |
| ReLU INT8 Normal | `model/yolov5s_relu_INT8_Normal.rknn` | 使用常规 sigmoid 后处理。 |
| ReLU INT8 Graph-optimized | `model/yolov5s_relu_INT8_graphopt_check2.rknn` | 模型输出已是激活后结果，运行时需要 `--skip-sigmoid`。 |

## 构建

```bash
cd /home/orangepi/streamer_codev5.0/Desktop
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
```

运行前设置 RKNN 与 RGA 动态库路径：

```bash
export LD_LIBRARY_PATH=/home/orangepi/streamer_codev5.0/Desktop/3rdparty/librknn_api/aarch64:/home/orangepi/streamer_codev5.0/Desktop/3rdparty/rga/RK3588/lib/Linux/aarch64:$LD_LIBRARY_PATH
cd build
```

## 纯 RKNN 吞吐复现

Normal 模型：

```bash
./app --mode rknn-only --threads 6 --loops 900 \
  --model-path ../model/yolov5s_relu_INT8_Normal.rknn --warmup 50
```

Graph-optimized 模型：

```bash
./app --mode rknn-only --threads 6 --loops 900 \
  --model-path ../model/yolov5s_relu_INT8_graphopt_check2.rknn \
  --skip-sigmoid --warmup 50
```

`--warmup 50` 不计入统计，用于排除 RKNN context 初始化和频率爬升对吞吐测量的影响。

## 视频/摄像头模式

将上述 `--model-path` 参数添加到既有 `mpp-only` 或 `rtmp` 命令即可。仅 graph-optimized 模型需要额外带上 `--skip-sigmoid`；否则后处理会对已激活的输出重复做 sigmoid，检测框置信度和坐标会不正确。

模型文件是部署产物，不包含原始 ONNX、训练数据或 RKNN-Toolkit2 转换环境；这些内容不在本仓库中。
