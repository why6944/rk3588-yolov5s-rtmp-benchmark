# 新 RKNN 模型复现实验

本仓库包含两份用于对比的 YOLOv5s INT8 RKNN 模型：

| 模型 | 路径 | 输出说明 |
| --- | --- | --- |
| ReLU INT8 Normal | `model/yolov5s_relu_INT8_Normal.rknn` | 当前默认模型。输出已激活，后处理必须跳过 sigmoid。 |
| ReLU INT8 Graph-optimized | `model/yolov5s_relu_INT8_graphopt_check2.rknn` | 输出已激活，后处理必须跳过 sigmoid。 |

## 构建

```bash
cd /home/orangepi/streamer_codev5.0/Desktop
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
```

运行前设置 RKNN 与 RGA 动态库路径：

```bash
export LD_LIBRARY_PATH=/home/orangepi/streamer_codev5.0/Desktop/3rdparty/librknn_api/aarch64:/home/orangepi/streamer_codev5.0/Desktop/3rdparty/rga/RK3588/lib/Linux/aarch64:$LD_LIBRARY_PATH
cd build
```

## 纯 RKNN 吞吐复现

Normal 模型（默认，无需额外指定模型或 sigmoid 参数）：

```bash
./app --mode rknn-only --threads 6 --loops 900 --warmup 50
```

Graph-optimized 模型：

```bash
./app --mode rknn-only --threads 6 --loops 900 \
  --model-path ../model/yolov5s_relu_INT8_graphopt_check2.rknn \
  --skip-sigmoid --warmup 50
```

`--warmup 50` 不计入统计，用于排除 RKNN context 初始化和频率爬升对吞吐测量的影响。

## 视频/摄像头模式

程序默认使用 `yolov5s_relu_INT8_Normal.rknn`。模型路径中包含 `relu` 时，程序会自动启用 `skip_sigmoid=1`；因此既有 `mpp-only` 或 `rtmp` 命令无需额外添加模型参数。

若切回旧的 `yolov5s.rknn`，程序会自动使用标准 sigmoid；也可显式传入 `--apply-sigmoid`。`--skip-sigmoid` 与 `--apply-sigmoid` 用于在模型输出语义已确认时强制覆盖自动策略。对已激活输出重复做 sigmoid 会导致候选框数量异常和检测坐标不正确。

模型文件是部署产物，不包含原始 ONNX、训练数据或 RKNN-Toolkit2 转换环境；这些内容不在本仓库中。
